# gobrowser 开发者指南（DX 设计稿）

> 面向"用这套底座写业务程序的人"。回答两个问题：**我怎么开发？我怎么发布？**
> 文中 API 是目标形态（P1 落地），不是已实现代码。

---

## 0. 三种角色，先分清

| 角色 | 手里有什么 | 需要做什么 |
|---|---|---|
| **平台方**（你） | Electron 加固包、SDK、CLI、文档 | 维护运行时 + SDK + 打包工具 |
| **应用开发者** | Go SDK + 运行时目录 + 文档 | 写 Go + 前端 + `app.json`，不碰 Electron |
| **最终用户** | 一个 exe（或一个目录） | 双击 |

开发者**永远不需要**知道 Electron、`package.json`、`main.js`、node_modules 的存在。

---

## 1. 上手：10 分钟出第一个窗口

### 1.1 项目结构（开发者只碰这三个东西）

```
MyApp\
├── main.go            ← 业务 + 起 HTTP 服务 + 调窗口 API
├── app.json           ← 应用声明（源码里就叫这个名；出包时改名成 <程序名>.app.json）
├── web\               ← 前端页面（普通网页，随便用什么框架）
│   └── index.html
└── icon.png
```

### 1.2 `main.go`：就三行

```go
package main

import "github.com/zwccn/gobrowser"

func main() {
    gobrowser.New(gobrowser.Config{Title: "报表中心"}).Show()
}
```

要自己的页面，把 `Show()` 换成 `ShowDir("./web")` / `ShowFS(embedFS)` / `ShowURL(url)`；
要尺寸就加字段：`gobrowser.Config{Title: "报表中心", Width: 1200, Height: 800, Frameless: true}`。

业务 API 和页面共用一个服务，顺手挂上：

```go
gobrowser.New(cfg).
    HandleFunc("/api/list", listHandler).
    ShowDir("./web")
```

要精细控制就用非阻塞的 `Start()`：

```go
app := gobrowser.New(gobrowser.Config{Title: "报表中心", Frameless: true})
app.HandleFunc("/api/list", listHandler)
if err := app.Start(); err != nil {
    gobrowser.Fatal("com.acme.report", err)
}
w := app.Window()
w.SetTitle("报表中心 · 已连接")
w.Maximize()
_ = app.Wait()
```

### 1.3 `app.json`（可选：用类库时不用手写）

> 同一个目录放多个产品时，配置文件必须和 exe 同名（`ReportOne.app.json` / `ReportTwo.app.json`），
> 否则会互相覆盖。SDK 的查找顺序：`<程序名>.app.json` → `app.json`（单产品目录的旧写法仍可用）。

```jsonc
{
  "appId": "com.acme.report",   // 全局唯一，决定数据隔离目录
  "name": "报表中心",
  "version": "1.2.0",
  "window": { "width": 1280, "height": 800, "frame": false, "icon": "icon.png" },
  "tray":   { "enabled": false },
  "preferBundled": true
}
```

> `entry.url` / `events` 由 SDK 自动填（它知道自己监听的端口），开发者不用管。

### 1.4 前端：普通网页，多两个能力

```html
<!-- 无边框窗口的拖动区：一行 CSS -->
<header style="-webkit-app-region: drag">
  报表中心
  <button style="-webkit-app-region: no-drag" onclick="gobrowser.window.minimize()">—</button>
  <button style="-webkit-app-region: no-drag" onclick="gobrowser.window.toggleMaximize()">□</button>
  <button style="-webkit-app-region: no-drag" onclick="gobrowser.window.close()">×</button>
</header>
```

- 不用打包器、不用 `import`：`window.webshell` 是外壳注入的，任何页面直接可用。
- 不需要窗口按钮？那就完全是个普通网页，什么都不用改。

### 1.5 本地开发循环

```bash
go run .                            # 最常用：SDK 自动找同级 runtime；没有就自动下载（只下一次）
go run ./tools/doctor -dir .        # 体检：运行时齐不齐、配置/端口/GPU 有没有问题
```

> 首次 `go run .` 若本机没有运行时，会打印进度并下载到 `%LOCALAPPDATA%\gobrowser\runtimes\`（约 80 MB，几十秒）；
> 之后秒开。内网/离线用 `GOBROWSER_RUNTIME_BASE` 指镜像，或 `GOBROWSER_RUNTIME_DIR` 指向本地 zip 目录。

找不到运行时的时候，控制台直接告诉你缺什么、放哪里（见架构方案 §2），不会白屏。

## 2. 发布：一条命令出全部平台

```bash
# 组装运行时（一次）
go run ./tools/pack -dist <electron dist> -out D://Apps//runtime -app ./app

# 出包（GUI 子系统，双击不弹控制台）
go run ./tools/build -targets win-x64,linux-arm64 -bundle bundled -out dist -iss

# 想要"一个 exe 搞定"（runtime 内嵌，首次运行自动释放）
go run ./tools/build -targets win-x64 -single -zips C://aitools//00.360易创 -out dist
```

> Windows 打包固定加 `-H windowsgui`，所以**不会出现控制台窗口**；
> 代价是没有 stdout，所以启动失败会写 `%LOCALAPPDATA%\<appId>\logs\shell.log` 并弹原生错误框。
> CI 里可设 `GOBROWSER_SILENT=1` 跳过弹框。

| 参数 | 说明 |
|---|---|
| `-targets` | 目标平台，逗号分隔：`win-x64` / `win-x86` / `linux-x64` / `linux-arm64` / `linux-loong64` / `linux-mips64el` |
| `-bundle bundled` | 发布目录里带 `runtime\`（客户机器干净时用） |
| `-bundle shared` | 只出 exe + `<程序名>.app.json`（客户已有运行时） |
| `-runtime-dir` / `-zips` | 运行时从本机现成目录复制 / 从官方 zip 解出 |
| `-single` | 单文件：runtime 压进 exe 尾部，首次运行自动释放 |
| `-iss` | 额外生成 Inno Setup 脚本 |
| `-out` | 输出目录 |

**产物：**

```
dist\
├── win-x64\
│   ├── ReportCenter.exe        ← 1.9 MB
│   ├── ReportCenter.app.json   ← 与 exe 同名
│   ├── icon.png
│   └── runtime\             ← 仅 bundled，约 180 MB
└── linux-arm64\
    ├── ReportCenter
    ├── ReportCenter.app.json
    └── runtime\
```

打包工具自动做的事（开发者不用记）：
版本号一致性校验 → 生成 Windows `.syso`（图标/版本/公司名）→ 交叉编译 → 组装 → 校验 runtime 完整性 → 压缩。

## 3. 交付给客户：两种放法

| 场景 | 放法 | 结果 |
|---|---|---|
| 客户机器**已装**其它产品（已有 runtime） | 只把 `ReportCenter.exe` + `ReportCenter.app.json` 拷进那个统一目录 | 复用同一份运行时，磁盘只多 2 MB |
| 客户机器**干净** | 整个 `dist\win-x64\` 目录拷过去 | 自带运行时，自包含 |

```
D:\Apps\                       ← 统一目录
├── runtime\                   ← 一份，所有产品共用
├── ReportOne.exe + ReportOne.app.json
├── ReportTwo.exe + ReportTwo.app.json
└── ReportThree.exe + ReportThree.app.json  ← 三个产品，磁盘只花一份 runtime
```

开发和发布用的是**同一份 exe**，bundled/shared 只是目录里放不放 `runtime\`，不需要打两个包。

## 4. SDK 覆盖的能力（开发者日常会用的）

| 需求 | 写法 |
|---|---|
| 开窗口 / 关窗口 | `app.Window("main")` / `w.Close()` |
| 最大化 / 最小化 / 全屏 | `w.Maximize()` / `w.Minimize()` / `w.SetFullScreen(true)` |
| 置顶 / 透明度 | `w.SetAlwaysOnTop(true)` / `w.SetOpacity(0.9)` |
| 改标题 / 改大小 | `w.SetTitle("…")` / `w.SetBounds(0,0,1280,800)` |
| 托盘 | `app.Tray().SetIcon("icon.png").SetMenu(items…)` |
| 文件对话框 | `app.Dialog().OpenFile(filters…)` |
| 通知 / 剪贴板 | `app.Notify(title, body)` / `app.Clipboard().WriteText(s)` |
| 全局快捷键 | `app.Shortcut("Ctrl+Alt+F1", func(){ w.Show(); w.Focus() })` |
| 收事件 | `OnEvent` 回调（只发低频事件：窗口关闭/最大化/托盘点击/二次启动；不含 focus/blur/resize） |
| 多窗口 | `app.NewWindow(shell.WindowOptions{ URL: "/detail" })` |

没被 SDK 包住的能力也能用 —— SDK 只做薄封装，底层就是 HTTP：`app.Raw().Post("/v1/windows/main/maximize", nil)`。

## 5. 版本契约（谁能升级、升了会不会坏）

| 组件 | 版本 | 谁升级 | 兼容规则 |
|---|---|---|---|
| Runtime（Electron 加固版） | 1.0.x | 平台方 | 运行时升级对开发者透明 |
| Go SDK | v1.x | 开发者 `go get -u` | SDK v1 支持 runtime `>=1.0 <2` |
| `app.json` schema | 1 | 平台方（只增字段） | 新增字段有默认值，旧版不崩 |

- **运行时升级不需要重编业务程序** —— 换 `runtime\` 目录即可。
- **SDK 升级不需要重打运行时** —— 只重编 exe（2 MB，几秒）。
- 两边解耦，是这套架构最大的工程收益。

## 6. 出问题时开发者怎么排查

```bash
go run ./tools/doctor -dir .          # 找到哪个 runtime？版本够不够？端口能绑吗？GPU 可用吗？
```

典型输出（`✓` / `!` / `✗` 三态）：

```
gobrowser doctor
目录: D:\Apps
────────────────────────────────────────────────────────────────────
 ✓ 运行时      D:\Apps\runtime · version=16.0.9
 ✓ 外壳程序    D:\Apps\runtime\gobrowser.exe
 ✓ electron.sign  72 B
 ✓ resources\app.asar  19456 B
 ✓ lic/        1 个 .lic 文件
 ✓ 端口        可绑定 127.0.0.1:52341（每次启动随机分配）
 ! 显卡        检测到远程桌面会话，建议 app.json 设 "gpu": "disable"
```

日志位置：`%LOCALAPPDATA%\<appId>\logs\shell.log`（Linux: `~/.local/state/<appId>/logs/`）。

## 7. 平台方还需要交付什么（你的工作量清单）

| 交付物 | 内容 | 面向 |
|---|---|---|
| runtime 包 | 每个平台一份 zip（含 sign / lic / asar） | 开发者 / 运维 |
| Go SDK | `gobrowser` 包 + 示例 | 开发者 |
| 工具 | `go run ./tools/{pack,relruntime,build,doctor}` | 开发者 |
| 示例工程 | 一个最小可跑（含无边框标题栏 + 托盘 + 事件） | 开发者 |
| 文档 | 本指南 + API 参考 + 架构方案 | 开发者 |
| 变更记录 | runtime / SDK 版本与兼容性 | 全员 |

## 8. 开发者视角的一天（串起来）

```
09:30  git clone 示例工程 → go run .          → 窗口起来了（10 分钟内）
10:00  写前端页面（Vue/React/原生都行）        → 起 vite dev server，ShowURL 指过去（热更新）
11:00  加托盘、加无边框标题栏按钮             → window.webshell
14:00  go run ./tools/doctor -dir .            → 检查环境
15:00  go run ./tools/build -targets win-x64,linux-arm64 -bundle bundled
16:00  把 dist\win-x64 拷到客户机 → 双击       → 完成
```
